Price Context Guide

Read a visible number with its currency, option, quantity, time, and page context.

A number is not a price

A number only becomes a price when its context is attached. Read the number, then read what it sits next to.

Currency

The currency tells you what the number is denominated in. Without it, the number is unreadable.

Option

Which color, size, or version the number applies to. A price always belongs to a specific option.

Quantity

Whether the number is for one unit or a set. A per-unit price and a set price are not the same.

Time

A price is a snapshot at a moment. It may have changed since the row was written.

Page context

The destination page is where the number is finally confirmed — with any visible conditions.

A worked read

  1. Number: a figure shown on a page.
  2. Context: currency, option, and quantity next to it.
  3. Confirmed: the page is where it is re-checked.
